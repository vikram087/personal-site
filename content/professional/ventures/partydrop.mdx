Built PartyDrop, a text-native ticketing platform — no app, no browser, the entire purchase flow happens over messages. Deployed an AI agent that autonomously handles identity verification, event Q&A, and Stripe payments via tool calls, backed by a real-time message delivery pipeline with batch processing, retries, and idempotency. Handled 11,500+ messages from 850+ users and generated $5,000+ in revenue.

See more at [partydrop.live](https://partydrop.live).
