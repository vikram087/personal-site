Production engineering fellowship focused on deploying and operating real
services.

- Developed and deployed a web app on a DigitalOcean CentOS server using Flask.
- Containerized the application with Docker, orchestrating Flask, MySQL, and

- Created a CI/CD pipeline on GitHub Actions running unit tests and bash
  scripts to automate deployments.
- Implemented Prometheus and Grafana for monitoring, with Systemd keeping
  uptime at a maximum.
